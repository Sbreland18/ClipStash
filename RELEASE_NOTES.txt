Version 1.3.0

- Clip a section: download just part of a video by entering a start and
  end time, instead of the whole thing
- Remove sponsors: strips sponsor readings, self-promotion, intros and
  outros using the SponsorBlock database
- Pause and resume a download without losing progress
- ClipStash flashes in the taskbar when a queue finishes and you're
  working in another window
- Portable mode: put an empty file named portable.txt next to
  ClipStash.exe and all settings, logs and history are kept in a Data
  folder beside it, so it can travel on a USB stick
